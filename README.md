# Latent Gate MoE

Official implementation of **"Latent Gate Routing for Mixture-of-Experts Transformers"**
(technical note FSP-2026-0330).

This work builds on gated latent routing (FSP-2026-0417) but is a separate paper with its own
method and experiments. This repository does not contain an implementation of the earlier
routing note; it implements the mixture-of-experts variant only.
